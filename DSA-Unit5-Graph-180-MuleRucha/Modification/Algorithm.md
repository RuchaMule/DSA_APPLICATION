## Algorithm

1. Start.

2. Input the number of locations and roads.

3. Create a weighted graph and store the roads with their distances.

4. Input the source and destination locations.

5. Validate the source and destination.

6. Apply Dijkstra’s algorithm to calculate the shortest route before updating the graph.

7. Display the shortest route and total distance. If no path exists, display an appropriate message.

8. Input a new road’s source, destination, and distance.

9. Validate the new road details.

10. Add the new road to the graph and display the updated graph.

11. Apply Dijkstra’s algorithm again to find the updated shortest route.

12. Display the updated route and total distance, or display a message if no path exists.

13. Compare the shortest-path results before and after the update.

14. Stop.
