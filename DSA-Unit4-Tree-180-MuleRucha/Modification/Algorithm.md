## Algorithm

1. Start the program.
2. Define a `Node` structure containing data, left and right pointers, and thread flags.
3. Accept the number of nodes and their values from the user.
4. Insert the values into the Threaded Binary Search Tree (TBST).
5. Perform inorder traversal and store the values.
6. Find the inorder predecessor and successor of every node.
7. Display `Not Exists` when a predecessor or successor is unavailable.
8. Compare the results with the inorder traversal sequence.
9. Display the verification result.
10. Stop the program.
