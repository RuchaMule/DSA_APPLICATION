Implement College Lost & Found Management System using Singly Linked List, Stack, and Queue in C++. The system stores details of lost and found items such as Item ID, Item Name, and Status (Lost/Found). It allows users to add, search, display, and remove items using a linked list. Stack operations (Push and Pop) and Queue operations (Enqueue and Dequeue) are implemented using linked lists. The system also demonstrates dynamic memory allocation using the calloc() function.
